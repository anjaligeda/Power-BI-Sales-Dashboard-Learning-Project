# 📊 Sales Dashboard – Power BI Practice Project

## 📌 About the Project

This is my first Power BI practice project, created while learning and exploring Power BI.

The main goal of this project was to understand the fundamentals of Power BI and practice transforming raw sales data into interactive dashboards and visualizations.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📚 What I Practiced

Through this project, I practiced:

- Importing data into Power BI
- Cleaning and transforming data using Power Query
- Creating charts and visualizations
- Creating KPIs
- Using slicers and filters
- Creating basic DAX calculations
- Designing an interactive dashboard
- Analyzing sales trends and performance

## 📊 Dashboard Preview

The `.pbix` file contains the complete Power BI dashboard.

## 🎯 Learning Outcome

This project helped me build a foundational understanding of Power BI and gave me hands-on practice with:

- Data preparation
- Power Query
- Basic DAX
- Data visualization
- Dashboard design
- Interactive reporting

I am continuing to build more projects to strengthen my practical data analytics skills and develop my portfolio as I work toward becoming a Data Analyst.
